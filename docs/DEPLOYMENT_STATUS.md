# Deployment status

## Frontend

The static application is deployed from `architecture/modular-refactor` through `.github/workflows/deploy-pages.yml`. The workflow validates the required frontend files, runs `npm test` and `npm run check`, uploads the repository root as a Pages artifact, and deploys it to GitHub Pages.

Expected public URL: https://argeliovigoa.github.io/Data-Analyzer/

A successful GitHub Actions deployment and a public HTTP check are required before treating the site as live.

## Backend

The FastAPI backend is described by the root `render.yaml` Blueprint and uses the free Render web-service plan. It requires a PostgreSQL `DATABASE_URL` configured privately in Render before the service can pass its `/health` check. `JWT_SECRET_KEY` is generated by the Blueprint. Do not commit credentials or database URLs to this repository.

The frontend and backend are not yet integrated automatically: configure the API base URL in the frontend only after the backend health endpoint is publicly verified.

## Capability boundaries

AI providers are not connected, the AI provider remains a test Mock, and quantum algorithm execution is not available. The Pages deployment publishes the current static frontend; it does not enable these unfinished features.

QuoLab Data Analizer

Entorno para importar, inspeccionar y organizar datos científicos de física nuclear, como base para futuros métodos cuánticos. Hoy es un esqueleto: ningún algoritmo es ejecutable.

ILUSTRACIÓN DECORATIVA · no es una simulación ni ejecuta cálculos

Disponible en nivel 1

  • Importación local de archivos compatibles
  • Análisis estadístico automático, gráficos (Plotly por CDN), correlaciones y regresión
  • Registro de problemas científicos
  • Catálogo informativo de algoritmos
  • Exportaciones actuales (original, CSV, JSON, informe HTML)

Objetivos futuros (no disponibles)

  • Ejecución real de algoritmos cuánticos y simulaciones
  • Comparación entre métodos clásicos y cuánticos
  • Procesamiento avanzado de datos y gráficas
  • Integración con backends científicos
  • Integración completa con el ecosistema Quolab (no implementada)

QUOLAB DATA ANALIZER — SCIENTIFIC WORKFLOW

From experimental data to quantum-assisted scientific analysis.

STEP 01

Experimental Data Input

El investigador podrá incorporar archivos con datos experimentales (CSV, TSV, JSON y otros formatos de texto). El sistema los lee localmente en el navegador, sin enviarlos a ningún servidor.

Disponible en nivel 1
ILLUSTRATIVE · no son datos ni resultados
STEP 02

Data Inspection & Analysis

Inspección de la estructura de los datos y análisis clásico preliminar: tipos, estadísticas descriptivas, valores ausentes, duplicados y posibles atípicos. Incluye estadísticas, histogramas, boxplots y correlaciones (gráficos vía Plotly, requiere conexión).

Análisis estadístico y gráficos disponibles
ILLUSTRATIVE · no son datos ni resultados
STEP 03

Scientific Problem Formulation

El investigador define el problema científico o matemático a partir de los datos: variables, unidades, parámetros, hipótesis y restricciones. Hoy el espacio de trabajo solo registra esas decisiones; no construye modelos.

Registro disponible · formulación automática: futuro
ILLUSTRATIVE · no son datos ni resultados
STEP 04

Quantum Algorithm Selection

Una vez formulado el problema, se podrá estudiar qué algoritmos cuánticos son matemáticamente apropiados. VQE: energías de Hamiltonianos adecuados. QAOA: optimización combinatoria bien formulada. QAE: amplitudes o probabilidades. No se aplican automáticamente a cualquier archivo: exigen una formulación compatible.

Catálogo informativo · no ejecutable
ILLUSTRATIVE · no son datos ni resultados
STEP 05

Results, Visualization & Comparison

Objetivo final: obtener resultados, visualizarlos y, progresivamente, compararlos con métodos clásicos de referencia, con informes científicos. Es una meta; hoy no existe ejecución ni comparación.

Objetivo futuro
ILLUSTRATIVE · no son datos ni resultados
